## 🗺️ Роудмап разработки

> Пошаговый план разработки Multi-Tenant SaaS от нуля до продакшена

### 📍 Этап 0: Подготовка и планирование (1-2 дня)

**Цель:** Определить архитектуру, стек и структуру проекта

- [ ] Изучить [технологический стек](./стек.md) и выбрать компоненты
- [ ] Прочитать [Multi-Tenant архитектуру](./SaaS%20multi-tenant%20.md) - понять общую структуру
- [ ] Изучить [схему данных](https://drive.google.com/file/d/1hLkOHkSjyJlRGWtF4_jLb2cJElC0Sz0G/view?usp=sharing) - визуальное представление БД
- [ ] Изучить [потенциальные проблемы](./ОП%20потенциальных%20проблем%20и%20сложностей%20в%20Multi-tenant%20SaaS.md) заранее
- [ ] Изучить [Git Flow и стандарты разработки](./Git%20Flow%20и%20совместная%20разработка.md) - правила работы с Git
- [ ] Настроить Git репозиторий с защищенными ветками
- [ ] Определить доменное имя для SaaS
- [ ] Выбрать хостинг (VPS или облако)
- [ ] Создать структуру проекта
- [ ] Изучить [структуру проекта](./проект.md) - детальная структура папок и файлов

**Результат:** Четкое понимание архитектуры и готовность к разработке

### 📍 Этап 1: Базовая инфраструктура (3-5 дней)

**Цель:** Настроить проект, БД и базовые сервисы

- [ ] Создать ASP.NET Core 8 проект

- [ ] Настроить структуру папок (Data, Services, Features, Controllers)
- [ ] Установить базовые пакеты:
  - Entity Framework Core
  - ASP.NET Core Identity
  - Serilog (структурированное логирование)
- [ ] Создать MasterDbContext (мастер-база для тенантов)
- [ ] Создать TenantDbContext (шаблон для клиентских БД)
- [ ] Настроить appsettings.json с connection strings
- [ ] Настроить DI контейнер (базовые сервисы)
- [ ] Добавить [.editorconfig](./.editorconfig) для единого стиля кода
- [ ] Настроить CI/CD pipeline (базовый)

**Документация:**
- [Качество кода](./Качество%20кода.md) - стандарты с первого дня
- [Entity Framework Core](./Entity%20Framework%20Core.md) - настройка DbContext
- [Git Flow](./Git%20Flow%20и%20совместная%20разработка.md) - стандарты коммитов и веток

**Результат:** Работающий проект с подключением к БД

## 🎯 Ключевые принципы

### ✅ Делай так:
- **Один стек** - C#/.NET для всего проекта
- **Изоляция данных** - отдельная БД на каждого клиента
- **Тонкие контроллеры** - только транспорт, логика в сервисах
- **Расширения EF Core** - вместо репозиториев
- **View Components** - вместо копипасты разметки
- **Структурированное логирование** - с TenantId и UserId
- **Распределенный кэш** - Redis для мультитенантной системы

### ❌ Никогда не делай:
- `IRepository<T>` - антипаттерн для EF Core
- `.Result` или `.Wait()` - только async/await
- `new HttpClient()` - используй IHttpClientFactory
- Копипаст разметки - используй View Components
- Общий ключ кэша для всех клиентов - всегда `tenant:{id}:key`
- Миграции вручную по каждой БД - автоматизируй
